# Selenium WebDriver Tests with Page Object Pattern

## Рефакторинг тестов с использованием паттерна Page Object

### Структура проекта

```
├── pages/                    # Page Object классы
│   ├── BasePage.js          # Базовый класс с общими методами
│   ├── LoginPage.js         # Страница авторизации
│   ├── PracticeFormPage.js  # Страница Practice Form
│   ├── WebTablesPage.js     # Страница Web Tables
│   └── TextBoxPage.js       # Страница Text Box
├── task2_tests_refactored.js # Обновленные тесты с Page Object
├── task2_tests.js           # Исходные тесты (для сравнения)
└── package.json
```

### Что было сделано

1. **Page Object Pattern**:
   - Созданы отдельные классы для каждой страницы
   - Каждый класс инкапсулирует локаторы и методы работы с элементами
   - Базовый класс `BasePage` содержит общие методы (ожидание, клик, ввод текста и т.д.)

2. **Опции браузера**:
   - Добавлены дополнительные опции для Edge:
     - `--start-maximized` - запуск в максимальном размере
     - `--disable-notifications` - отключение уведомлений
     - `--disable-popup-blocking` - отключение блокировки всплывающих окон
     - `--disable-infobars` - отключение информационных панелей
     - `--disable-extensions` - отключение расширений
     - `--disable-gpu` - отключение GPU (для стабильности)
     - `--no-sandbox` - отключение песочницы
     - `--disable-dev-shm-usage` - оптимизация использования памяти
     - `--disable-software-rasterizer` - улучшение производительности
     - `--disable-background-timer-throttling` - отключение троттлинга таймеров

3. **Преимущества нового подхода**:
   - **Поддержка**: Локаторы хранятся в одном месте, легко обновлять
   - **Читаемость**: Тесты стали более понятными и лаконичными
   - **Переиспользование**: Общие методы вынесены в базовый класс
   - **Надежность**: Улучшена обработка ожиданий и ошибок

### Как запустить тесты

```bash
# Установка зависимостей (если еще не установлены)
npm install

# Запуск оригинальных тестов
node task2_tests.js

# Запуск обновленных тестов с Page Object
node task2_tests_refactored.js
```

**Примечание**: Тесты с Page Object успешно проходят все 11 проверок.

### Пример использования Page Object

```javascript
// Старый подход
await driver.findElement(By.id("userName")).sendKeys("testUser");
await driver.findElement(By.id("password")).sendKeys("password");
await driver.findElement(By.id("login")).click();

// Новый подход с Page Object
const loginPage = new LoginPage(driver);
await loginPage.login("testUser", "password");
```

3. **Цветовой вывод**: Сохранен цветной вывод результатов в консоль
4. **Обработка ошибок**: Улучшена обработка исключений и таймаутов

### Работа с куками и скриншотами

Добавлен новый тестовый файл `task3_cookies_screenshots.js`, который демонстрирует:

#### Работа с куками:
1. **Получение всех куков** - метод `getAllCookies()`
2. **Получение куки по имени** - метод `getCookieByName(name)`
3. **Сохранение куков в файл** - автоматическое сохранение в формате JSON
4. **Удаление куков** - методы `deleteCookieByName(name)` и `deleteAllCookies()`
5. **Анализ куков** - группировка по доменам, анализ сроков действия

#### Скриншоты:
1. **Автоматическое создание скриншотов** - метод `takeScreenshot(filename)`
2. **Скриншоты на разных этапах** - главная страница, после авторизации, после удаления куков
3. **Скриншоты разных страниц** - Text Box, Checkbox, Radio Button, Web Tables, Buttons
4. **Организация скриншотов** - автоматическое создание папки `screenshots`

#### Созданные файлы:
- **12 скриншотов** в папке `screenshots/`
- **3 файла с куками** в папке `cookies/`:
  - `cookies_before_login.json` - куки до авторизации
  - `cookies_after_login.json` - куки после авторизации (17 кук)
  - `cookies_full_report.json` - полный отчет о куках с группировкой по доменам

#### Запуск теста с куками и скриншотами:
```bash
node task3_cookies_screenshots.js
```
