# Тесты для Magizoo.ru

Проект автоматизированного тестирования веб-сайта magizoo.ru с использованием Selenium WebDriver.

## Структура проекта

```
├── pages/                    # Page Object модели
│   ├── BasePage.js          # Базовый класс для всех страниц
│   ├── MagizooHomePage.js   # Главная страница magizoo.ru
│   ├── HomePage.js          # Общая домашняя страница
│   ├── ProductPage.js       # Страница продукта
│   └── SearchPage.js        # Страница поиска
├── utils/                   # Утилиты
│   └── browser.js          # Настройки браузера
├── tests.js                # Основные тесты с Mocha
├── simple-test.js          # Простые тесты без Mocha
├── package.json            # Зависимости и скрипты
└── README.md               # Документация
```

## Установка

1. Установите Node.js (версия 14 или выше)
2. Установите зависимости:

```bash
npm install
```

3. Убедитесь, что у вас установлен Chrome браузер
4. Убедитесь, что chromedriver совместим с вашей версией Chrome

## Запуск тестов

### Основные тесты с Mocha

```bash
# Установите Mocha глобально (если еще не установлен)
npm install -g mocha

# Запустите все тесты
npm test

# Или напрямую через Mocha
mocha tests.js --timeout 30000
```

### Простые тесты без Mocha

```bash
# Запуск простых тестов
node simple-test.js
```

### Тестирование отдельных функций

```bash
# Только тесты открытия главной страницы
npm run test:headless
```

## Page Object модели

### MagizooHomePage.js

Класс для работы с главной страницей magizoo.ru включает:

- **Методы навигации:**
  - `openHomePage()` - открытие главной страницы
  - `searchProduct(productName)` - поиск товара
  - `openCatalog()` - открытие каталога
  - `openContacts()` - открытие контактов
  - `openCart()` - открытие корзины
  - `clickRandomFooterLink()` - клик по случайной ссылке в футере

- **Селекторы элементов:**
  - `searchInput` - поле поиска
  - `catalogButton` - кнопка каталога
  - `contactsLink` - ссылка на контакты
  - `cartButton` - кнопка корзины
  - `loginButton` - кнопка входа
  - `firstProduct` - первый товар в списке
  - `footerLinks` - ссылки в футере

### BasePage.js

Базовый класс с общими методами для всех страниц:

- `open(url)` - открытие URL
- `waitForElement(selector)` - ожидание элемента
- `findElement(selector)` - поиск элемента
- `click(selector)` - клик по элементу
- `type(selector, text)` - ввод текста
- `getText(selector)` - получение текста элемента
- `isElementVisible(selector)` - проверка видимости элемента
- `sleep(ms)` - пауза
- `getCurrentUrl()` - получение текущего URL
- `getTitle()` - получение заголовка страницы

## Настройка тестов

### Таймауты

Тесты используют увеличенные таймауты (30 секунд) для учета времени загрузки страниц.

### Обработка ошибок

Тесты включают обработку ошибок и логирование для отладки. Если элемент не найден, тест пропускается вместо падения.

### Селекторы

Используются гибкие селекторы с несколькими вариантами для повышения устойчивости тестов.

## Отладка

Для отладки тестов:

1. Добавьте `console.log()` в методы Page Object
2. Используйте `await page.sleep(5000)` для пауз при отладке
3. Проверяйте логи в консоли
4. Убедитесь, что ChromeDriver совместим с вашей версией Chrome

## Примечания

- Тесты выполняют реальные запросы к сайту magizoo.ru
- Для работы тестов требуется стабильное интернет-соединение
- Структура сайта может меняться, что может потребовать обновления селекторов
- Рекомендуется запускать тесты в headless режиме для CI/CD
